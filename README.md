# Global Opportunity Lab

A free-first, evidence-driven research framework for discovering and validating short-term opportunities across global financial markets.

**Mandate:** 3–30 day horizon · medium risk framework · wait for confirmation · combined fundamental + technical + capital-flow + sentiment analysis.

## Operating rules
- Free/public sources first; verify API limits, licensing and data freshness before automation.
- Every candidate needs timestamped evidence and explicit counter-evidence.
- A score cannot override hard risk or data-quality gates.
- Preserve discovery-time prices and original theses; append updates rather than rewriting history.
- Social attention is a discovery input, never sufficient proof by itself.
