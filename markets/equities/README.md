# Equities Module

Check filings, earnings dates, guidance, revisions, margins, cash flow, balance sheet, valuation, float, dilution, insider transactions, short interest where reliable, sector/benchmark relative strength and liquidity. Treat earnings and regulatory decisions as gap-risk events.

Primary sources: SEC EDGAR (US issuers), issuer investor-relations pages, exchange notices and official index/ETF providers. Aggregators are discovery aids; verify material facts in primary documents.
