# Crypto Module

Assess spot and derivatives separately. Core checks: spot liquidity and venue concentration; market cap/float; unlocks/emissions; protocol usage, fees and revenue; token value capture; on-chain activity; exchange flows; funding/open interest; security/governance risks. TVL growth alone does not establish token value.

Free/public starting points (verify terms and coverage): CoinGecko, DefiLlama, DEX Screener, CoinGlass, exchange public endpoints, project documentation, governance forums, GitHub and on-chain explorers.

**Legacy specialist research:** [crypto-opportunity-lab](https://github.com/ehsanjafarpanah/crypto-opportunity-lab). It remains separate and unchanged. Its longer-horizon/high-upside thesis framework is not automatically equivalent to this lab's 3–30 day medium-risk process. Revalidate any reused idea under this lab's rules.
